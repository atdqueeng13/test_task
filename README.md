# Платформа обработки обращений в поддержку

Модуль на Python, имитирующий работу платформы для обработки обращений пользователей операторами поддержки.

## Описание

Система поддержки с чатами между операторами и пользователями:

- **Операторы** - обрабатывают обращения, назначаются случайным образом из свободных
- **Пользователи** - создают обращения и оценивают качество поддержки (CSAT 1-5)
- **Платформа** - управляет назначением операторов, историей переписки и выгрузками

Данные (люди, чаты, сообщения) генерируются случайным образом из заготовленных списков русских имён, городов, должностей и шаблонов переписки.

## Структура проекта

```
support_platform/              # Основной модуль
├── __init__.py
├── platform.py                # Класс SupportPlatform - ядро системы
├── generator.py               # Генерация данных и симуляция чатов
├── exporter.py                # Выгрузка данных в JSON + консоль
└── models/
    ├── __init__.py
    ├── person.py              # Базовый класс Person (ФИО, город, стаж)
    ├── operator.py            # Оператор - наследник Person
    ├── user.py                # Пользователь - наследник Person
    ├── message.py             # Сообщение в чате
    └── chat.py                # Чат (обращение) с историей и CSAT

scripts/                       # Демонстрационные скрипты
├── run.py                     # Полный цикл: генерация -> статистика -> выгрузки
├── demo_create_chats.py       # Сценарий: создание 100+ чатов
└── demo_export.py             # Сценарий: все возможные выгрузки

sql/                           # SQL-запросы (задания а-г)
├── task_a.sql
├── task_b.sql
├── task_c.sql
└── task_d.sql

exports/                       # Создаётся при запуске (в .gitignore)
```

## Запуск

```bash
# полный цикл: генерация, симуляция, статистика, все выгрузки
python scripts/run.py

# сценарий 1: создание 120 чатов, примеры переписки, актуализация данных
python scripts/demo_create_chats.py

# сценарий 2: демонстрация всех 5 видов выгрузок
python scripts/demo_export.py
```

## Выгрузки

Каждая выгрузка сохраняется в JSON-файл в папку `exports/` и выводит превью в консоль.

| Выгрузка | Файл | Описание |
|----------|------|----------|
| Все чаты | `all_chats.json` | Полная история всех обращений с сообщениями |
| Чаты оператора | `operator_N_chats.json` | Обращения конкретного оператора |
| Чаты пользователя | `user_N_chats.json` | Обращения конкретного пользователя |
| Профили операторов | `operators.json` | Данные всех операторов |
| Профили пользователей | `users.json` | Данные всех пользователей |

## SQL-запросы

| Файл | Задание | Описание |
|------|---------|----------|
| `task_a.sql` | а | Ники клиентов с оценкой CSAT меньше 3 |
| `task_b.sql` | б | Тикеты со словом «отлично», сортировка по CSAT |
| `task_c.sql` | в | Клиенты с более чем 5 заказами в «Теремке» и «Вкусно и точка», макс. сумма |
| `task_d.sql` | г | Объединение orders + clients + tickets (LEFT JOIN), 1000 записей |

Запросы написаны под PostgreSQL (в MySQL тоже работают).

## Требования

- Python 3.10+
- Только стандартная библиотека (без сторонних зависимостей)
